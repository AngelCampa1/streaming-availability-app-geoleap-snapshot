# How-to-Watch Guides

## Key Takeaways
- GeoLeap provides country-specific streaming availability for 200+ popular titles
- Guides cover movies, TV shows, and documentaries across 57 countries
- Each guide shows which platforms carry the title, pricing, and quality options
- Updated automatically as streaming rights change

## How It Works
Search for any movie or TV show on GeoLeap, select your country, and instantly see which streaming platforms carry it - including whether it's included with subscription, available to rent, or available to buy.

## URL Pattern
`https://geoleap.app/how-to-watch/{type}/{title-slug}/in/{country-slug}`

Types: `movie`, `tv-show`, `documentary`

## Browse Guides
- Browse all: https://geoleap.app/how-to-watch
- Search for any title: https://geoleap.app/search
